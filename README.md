#UniSA Programming Communtity discord bot

## Overview 
I developed this for the UniSA Programming Community (UPC) https://www.linkedin.com/company/unisa-pc/ during a 7 day long codejam. I've since made this open souce which can be found here (https://github.com/UniSA-Programming-Community/Discord-Bot).

It is developed using Discord.py and hosted on azure. 

## Functionality
- automatically remined people to renew there USASA membership prior to renewal.
- automatically remined people who have been in the server for longer then 7 days, and are not a member on USASA to sign up.
- create, delete and view upcoming events
- and more
