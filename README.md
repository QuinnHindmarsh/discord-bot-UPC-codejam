# UniSA Programming Communtity discord bot

## Overview 
I developed this for the UniSA Programming Community (UPC) www.linkedin.com/company/unisa-pc/ during a 7 day long codejam. I've since made this Open-Source which can be found here (github.com/UniSA-Programming-Community/Discord-Bot). If you are interested in contributing, please reach out to me. 

This bot is purely designed for the Unisa Programming Community discord server, and is not available for use outside of that. 

## Functionality
- automatically remind people to renew thier USASA membership prior to renewal.
- automatically remind people who have been in the server for longer than 7 days, and are not a member on USASA to sign up.
- create, delete and view upcoming events
- and more

## Technology used
- Python
- Discord.py
- JSON
- Azure server
- Aync functions
